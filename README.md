# Shycraft Docs

Public documentation for the Minecraft plugins developed for the Shycraft SMP network.

These docs are aimed at server owners who want to run the plugins on their own network. For player-facing help, ask your server administrator.

## Available Plugins

- **economy-core** — full economy, homes, teleportation, teams, kits, chat and utility commands in a single self-contained plugin.

More plugins will be added here over time.
