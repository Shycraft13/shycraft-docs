# RTP Zone (`economy/rtpzone/`)

Rectangular regions used by RTP as spawn candidates.

## `economy/rtpzone/config.yml`

```yaml

interval-seconds: 30

world: world

max-radius: 5000
min-radius: 500
center-x: 0
center-z: 0

title: "&#00A4FC&lRTPZONE"
subtitle: "&7Teleport in &#00A4FC%economy_rtpzone_time%"

sound: "minecraft:entity.enderman.teleport|1|1"

enter-sound: "minecraft:block.beacon.activate|1|1"

countdown-sound: "minecraft:ui.button.click"
```
