# Spawn (`economy/spawn/`)

Spawn point and /spawn command.

## `economy/spawn/config.yml`

```yaml
spawn:
  teleport-delay: 5

  use-bed-respawn: true
```

## `economy/spawn/messages.yml`

```yaml
messages:
  no-spawn-set: "&cSpawn has not been set yet."
  spawn-set: "&#00A4FC&lSPAWN &r&7» &fSpawn location has been set."
  teleporting: "&#00A4FC&lSPAWN &r&7» &fTeleporting to spawn..."
  already-teleporting: "&cYou are already teleporting."
```

## `economy/spawn/sounds.yml`

```yaml
sounds:
  teleport: "minecraft:entity.enderman.teleport|1.0|1.0"
```
